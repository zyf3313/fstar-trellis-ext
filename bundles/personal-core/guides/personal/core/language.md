# Language and discovery

**Trigger:** Write rules or user deliverables.

Write concise English AI rules, indexes, workflow and skill instructions with stable terms/IDs and explicit triggers. Write user PRDs, technical/UI designs, questions, reviews and delivery reports in Chinese. Preserve real code identifiers, paths, commands, schemas and Trellis parser markers. Keep domain terms when needed; do not maintain duplicate full translations. Use one authoritative document per responsibility. English alone is not evidence of better accuracy or lower token cost.
