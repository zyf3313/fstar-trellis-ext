# Design-first planning

**Trigger:** New project or large task.

Use Trellis Plan → Execute → Finish. New projects and cross-module/system work, substantial architecture changes, migrations/compatibility changes or independently verifiable deliveries require full planning. Discuss goals/scope, explore reference projects, write Chinese PRD, confirm applicable UI language/shell/interactions, write Chinese TDD, review/freeze, then activate and implement. Small fixes keep a lightweight path; affected UI behavior still needs a design basis. Preserve accepted scope and confirmation; do not ask the same implementation permission at each step.
