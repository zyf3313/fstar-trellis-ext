# Reference-project exploration

**Trigger:** New project, large task or important choice.

Define the decision, explicit source/provider requests and constraints. Follow [routing, budgets and runtime states](../tools/exploration/usage.md); reuse valid local research/current references before new queries. Expand only for an unresolved evidence gap or explicit scope. Provider-specific guidance is loaded on demand.

Write a Chinese report under the current task research directory using the exploration template. Record selection/reuse reasons, actual source/ref/date, claimed/original/source/trial evidence, adopt/adapt/reject reasoning and remaining limits. Map conclusions to PRD/TDD/UI IDs. Stop when the decision is resolved or results repeat. Completion is scoped to selected capabilities; unrequested sources do not block it, and selected unavailable requirements remain pending/restricted. Exploration does not post, DM or modify third-party repositories.
