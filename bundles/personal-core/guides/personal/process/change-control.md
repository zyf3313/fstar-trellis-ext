# Freeze and change consistency

**Trigger:** Freeze, change or deliver design.

Freeze covered scope, document/source versions and actual user confirmation evidence. Product changes update PRD and affected TDD/UI/task acceptance; contract/model/migration changes update TDD, authoritative protocols, consumers and tests; visual/interaction changes update source/tokens/components/artboards/gallery/exports/prototype and acceptance. Invalidate stale generated artifacts and evidence, regenerate and verify. Reconfirm only materially affected design; unchanged external behavior uses routine engineering checks. Before delivery trace requirement → design/UI → code/protocol → acceptance, and capture reusable learning in its owning spec. Mechanical consistency checks do not prove semantic or user acceptance.
