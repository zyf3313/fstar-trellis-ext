# personal-project-explore

Read `.trellis/spec/guides/personal/process/exploration.md` and `.trellis/spec/guides/personal/tools/exploration/usage.md` (before adoption: `specs/process/exploration.md` and `specs/tools/exploration/usage.md`). The tools rule owns provider routing, adjustable budgets and runtime states; load provider-specific guidance only for selected capabilities.

Start with explicit source/provider requests and constraints, then reuse available capabilities and valid evidence. Use short deduplicated candidates followed by focused originals/source; expand only for a recorded evidence gap or explicit scope. Unavailable requested items remain pending/restricted; unrequested special sources are `not_requested`. Compare accurate version, capability, license, fit and unknowns. Produce a Chinese report in the current task research directory using `.trellis/personal/templates/reports/exploration.zh-CN.md`, recording selection/reuse, budgets, actual tool count or unknown, runtime limits and stop basis; map decisions to PRD/TDD/UI IDs. Research authorization does not include posts/DMs/third-party writes.
