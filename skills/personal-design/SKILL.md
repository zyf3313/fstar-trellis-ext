# personal-design

For UI planning, prototyping or review, read `.trellis/spec/guides/personal/tools/ui-design.md` and [UI skill selection](references/ui-skills.md). Impeccable is the primary planner/reviewer/refiner; UI UX Pro Max supplies focused design and actual-stack guidance when needed. Initialization installs missing compatible providers. Verify their installed instructions/runtime; a missing provider remains a reported gap while independent drafting can continue. Preserve the confirmed baseline and authoritative document/source ownership. Additional search or critique is loaded only for a concrete gap.

Read `.trellis/spec/guides/personal/process/planning.md`, `document-ownership.md`, `ui-design.md` and `change-control.md`. Discover existing authoritative directories and reuse them. Use installed templates under `.trellis/personal/templates/product`, `technical`, `ui` and `review`. PRD covers background, business panorama, module responsibilities and per-function flows/acceptance. TDD retains twelve chapters and adapts contracts/diagrams to each function's type. UI projects confirm language/tokens/components, shell/navigation and feature states first; non-UI work records applicability. Provide an independent local preview scaffold with module/feature/state navigation, artboards and real interactive prototypes; document how to add modules. Deliver structurally validated editable exchange files and manual Figma/MasterGo import instructions, without uploading on the user's behalf. Record platform feedback separately. Freeze only after explicit user review with version/scope/confirmation references. Trellis task artifacts reference authoritative IDs/chapters rather than duplicate full documents. Check the design manifest before execution/delivery; hash checks complement semantic review. Update affected documents/source/artifacts/tests on changes and invalidate old evidence; reconfirm only materially affected design.
