# JavaScript conventions

**Trigger:** Project has a JavaScript package manifest.

Read actual module/runtime/build configuration and configured validation scripts. Preserve import/export boundaries, async error propagation and owned timers/listeners/resources. Browser and Node globals are target-specific. Follow current lint/format/test conventions; do not add TypeScript or a framework merely because a general reference uses one. This is a version-independent baseline, not a runtime compatibility claim. Version-sensitive APIs require actual project runtime evidence.

Source: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide ; acquisition/adaptation is recorded by the stack-sourcing process.
