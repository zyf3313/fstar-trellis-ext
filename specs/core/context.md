# Task continuity

**Trigger:** Enter/resume a task.

Confirm project, Git state, task phase, accepted scope and next unfinished acceptance criterion. Preserve other work. Reuse unchanged guidance in the current context; reload relevant originals after compaction. Structural questions use a healthy code graph; literal strings use scoped search. The main agent reads foundational architecture/design documents; the assigned implementation/check agent reads its role manifest, task artifacts, applicable specs and exact edit locations. Keep compact state in the existing task, not a second planning system. A search result locates evidence; it does not replace required originals.
