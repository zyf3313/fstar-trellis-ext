# CodeGraph routing

**Trigger:** Structural code question.

Prefer the healthy covered code graph for definitions/callers/callees/impact/focused context. Batch related sources and cap output. Trust structural index evidence within coverage; do not repeat a full grep/read exploration. Use literal search for strings/config/comments and targeted source/runtime checks for dynamic/unindexed relationships. Confirm freshness after edits before depending on relationships. Blank/unsupported code records real coverage gaps. GitNexus can replace CodeGraph after coverage/call validation, not as a second mandatory index.
