# Reusable delivery

**Trigger:** Package, update or release.

Use Trellis's native fixed-ref spec/workflow marketplace entries. Personal catalog selection, skills/templates/scripts and tool configuration are separate installed assets. Generate bundles from unique sources; do not hand-edit duplicates. Preserve project package/layer ownership, local changes and configuration. Compare installed base, local and target on upgrade; stage conflicting candidates and keep rollback evidence. Validate in independent consumers with differing stacks and real tool/runtime behavior. Keep private business documents, credentials, indexes/models/binaries and session data outside the published library. Remote identity/visibility/license and actual publishing need the applicable user instructions.
