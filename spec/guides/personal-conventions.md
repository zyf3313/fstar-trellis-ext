# Personal conventions

Apply only when selected for the current task. The project's native Trellis workflow,
existing spec indexes and local instructions remain authoritative.

- Write user-facing explanations and authored deliverable prose in Chinese unless requested otherwise.
  Keep identifiers, source quotations and protocol names accurate.
- Read foundational architecture/design originals and exact code before editing.
  Load only relevant guidelines; store long command logs locally and report outcomes.
- Preserve unrelated work and reuse authorization already given for the same scope.
- Report implementation, automated checks, environment skips and real user acceptance separately.
  Reuse evidence only for unchanged code, environment, command and scope.
- Resume from the existing task's compact state; do not create a second planning system.

These conventions were distilled from personal collaboration and execution preferences.
They do not add workflow phases or require a separate personal Skill.
