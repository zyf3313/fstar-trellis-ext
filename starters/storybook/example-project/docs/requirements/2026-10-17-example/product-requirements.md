> [!NOTE] 本文是 starter 样例，不是任何真实项目的业务决定。

## 背景与范围 {#scope}

评审发起人选择需求版本并邀请评审人。门户展示权威需求、技术方案、测试用例、长期设计资产和可交互原型。

## 业务流程 {#flow}

```flow
选择版本 | 发起人确认本次评审的源文件版本
邀请评审 | 评审人从稳定深链接进入案卷
记录结论 | 结论回写权威源或独立评审记录
```

## 邀请模块 {#invitation}

| 字段 | 规则 |
|---|---|
| `reviewer` | 必填，来自项目成员 |
| `deadline` | 可选，不能早于当前日期 |
| `message` | 最多 200 字 |
| `status` | 必填，只读展示，取值见 [REVIEW_STATUS](technical-design.md#dict-review-status) |

异常包括源文件缺失、版本漂移和邀请对象无访问权限。源文件缺失时生成必须失败，不能展示旧投影。

## 验收 {#acceptance}

- 文档修改后重新生成，页面哈希同步变化。
- 稳定 story ID 不因正文修改而变化。
- 窄屏页面不产生整体横向溢出。
