## 设计语言 {#language}

页面采用纸张感底色、深海军蓝、克制青绿和高密度技术排版。路径、版本与哈希使用等宽字体。

## 交互规则 {#interaction}

- 键盘焦点始终可见。
- 状态变化包含文字，不只依赖颜色。
- 减少动态效果偏好下缩短动画。
- 320 CSS px 起不产生页面级横向溢出。

## 资产所有权 {#ownership}

设计源长期保存在 `design/ui/`。需求归档只记录不可变版本引用，不移动长期设计资产。
