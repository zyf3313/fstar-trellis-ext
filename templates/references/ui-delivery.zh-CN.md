# UI 设计交付要求

设计语言与整体框架先确认；后续功能沿用同一 token/组件基线，按模块→功能→页面/状态组织。稳定 ID 关联 PRD/TDD、画板、原型、实现与验收。

一版交付含可编辑源、token/组件、功能清单、全部画板预览、独立可扩展的本地预览项目骨架、可启动点击/输入的原型、平台导入文件和实现参考。原型体现表单、导航、校验、加载/空/失败/权限、焦点和恢复；图片热点不能证明真实交互。

Figma/MasterGo 是目标导入平台。公开 Sketch 格式可作为交换候选；校验真实格式、可编辑图层/画板/文字及回读，提供手动导入入口和已知损失。用户自行导入，AI 不代上传；平台反馈单列。原生文件格式各自不同，自定义 JSON 不能改名冒充平台文件。平台登录与导入入口的前置条件在交付中明确。

生成产物记录源版本/依赖/映射。设计变化同步来源和受影响产物并使旧验收失效；平台人工修改通过已验证回读或明确同步更新源。自动测试、真实平台/设备与用户视觉接受分别记录。先验证一模块两功能后扩展。
